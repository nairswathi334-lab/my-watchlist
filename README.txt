UPDATE YOUR EXISTING GITHUB PAGES APP
1. Export a JSON backup from the app first.
2. Download and extract the ZIP.
3. Upload all five files to the root of your existing GitHub Pages repository, replacing files with the same names.
4. Commit the changes and refresh the website.
5. If the installed app still shows the old version, close it and reopen it after refreshing the website in Chrome.

WHAT'S NEW
- Cleaner home screen with appearance, sorting, backup and import controls in the Settings side panel.
- Compact poster tile shown for every saved title, including watched titles.
- Upload a poster image from your device, or provide a poster image URL.
- Add an optional file attachment such as a PDF, text note or document to a title.
- Open a title's details to view its description, language, genre, tags, rating and watched status.
- Uploaded images and attachments are stored in this browser with the watchlist. Keep files small and export backups regularly.

POSTERS & DESCRIPTIONS
- This static version does not automatically fetch official movie posters or verified synopses for all titles. Add a poster by uploading an image or entering an image URL, and enter a description in the title editor. Automatic poster/synopsis lookup needs a connected movie database/API service.

IN-APP RECOMMENDATIONS
- Smart Picks can match multiple selected genres and languages against your saved watchlist.
- “Suggest new titles in this app” displays curated titles inside the app and lets you add a title to your list.
- These suggestions use a built-in catalogue and matching logic, not a live generative AI model, and they do not open ChatGPT.

DATA & OFFLINE
- Your watchlist is saved in the current browser/device and is not automatically synced between devices.
- Once the app has loaded and cached, its core features and built-in suggestions can work offline.
- Back up your list before clearing browser data.
